# Laberinto - Juego en Pygame

## Descripción
Laberinto es un juego desarrollado en Python utilizando la biblioteca Pygame. El objetivo del jugador es navegar a través de un laberinto hasta llegar a la meta, evitando obstáculos y posibles peligros.

## Requisitos
Antes de ejecutar el juego, asegúrate de tener instalado Python y las dependencias necesarias. Puedes instalarlas con el siguiente comando:

```sh
pip install pygame
```

## Cómo ejecutar el juego
Para iniciar el juego, ejecuta el siguiente comando en la terminal dentro del directorio del proyecto:

```sh
python main.py
```

## Estructura del proyecto
El proyecto está compuesto por los siguientes archivos y directorios:

- `main.py`: Archivo principal que ejecuta el juego.
- `game.py`: Contiene la lógica principal del juego.
- `menu.py`: Maneja la interfaz del menú principal.
- `maze.py`: Contiene la generación y estructura del laberinto.
- `settings.py`: Archivo de configuración con parámetros del juego.
- `ui.py`: Maneja la interfaz gráfica dentro del juego.
- `stats.txt`: Archivo que almacena estadísticas del juego.
- `images/`: Carpeta que contiene los recursos gráficos.
- `win_sound.wav`: Sonido de victoria.
- `lose_sound.wav`: Sonido de derrota.

## Controles
- **Flechas** - Mover al personaje.
- **Cualquier teca** - Regresar al menú. (siempre y cuando se complete el juego)
